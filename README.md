# My Personal Website

Personal presentation website and portfolio, built with **HTML** and **Bootstrap 5** and hosted on **GitHub Pages**.

🔗 **Live site:** https://equalixlucacris.github.io/

## Sections

- **About me**: a short introduction
- **Skills**: the tools and technologies I work with
- **Projects**: a selection of my work
- **Contact**: where to find me

## Built with

- HTML5
- CSS3 (custom styles in `css/style.css`)
- [Bootstrap 5.3](https://getbootstrap.com/) via CDN
- GitHub Pages

## Project structure

```
EqualixLucaCris.github.io/
├── index.html
├── css/
│   └── style.css
├── img/
│   └── profile_pic.jpg
└── README.md
```

## Running locally

Clone the repository and open `index.html` in your browser. No build step or installation is required.

## About this project

Created as a hands-on way to learn the fundamentals of HTML, CSS and Bootstrap.
